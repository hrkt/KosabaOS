# ユーザーランドへの外出し設計 (2026-11-27)

カーネル本体の IwaC 化に向けた棚卸しから出てきた
決定の記録。テーマは「表示と起動の仕事をカーネルから
ユーザーランドへ出す」。各項目はユーザーの決定
(2026-11-27、IwaC チャットでの検討 + KosabaOS
チャットでの設計)。

## 決定

### 1. 時計表示はユーザープログラムへ

- 時計帯の描画 (proc.c の clock_body の lcd_tick_draw)
  はカーネルから外し、常駐プログラム (clock.elf) が
  uptime (syscall 31、既存) を読んで描く。新 syscall
  は不要
- カーネルに残るのは時刻を保つ仕事だけ。clock_body は
  WDT の餌やりとセーバー駆動だけの細いタスクになる
  (名前は実態に合わせて見直す)

### 2. 「生きている」表示はピクセル操作で

- 生存・進捗の表示はテキストでなく、線を引く・点を
  塗りつぶす・ブロックを点灯させる、で示す
  (fill rect 級の操作だけ)
- ブートスプラッシュのステップ行 ("STEP2 BOARD OK"
  等) はブロックの点灯に置き換える。ロゴ等の固定
  内容はビットマップを blit する

### 3. フォントはカーネルに置かない

- コンソールは UART で、流れるのは文字コードだけ。
  字形に焼くのは端末側の仕事なので、コンソール用
  フォントはカーネルに要らない
- 5x7 フォントは libdashi のような共用ライブラリに
  1 コピーだけ置き、テキストを描きたいプログラムが
  リンクして使う。現状の二重持ち (lcd.c の glyph() と
  ssd1315.c の oled_glyph()) は解消する
- clock.elf も libdashi フォントの利用者の1つ。
  libdashi 側の用意が要るので、当面は clock.elf の
  直持ちで先行してよい

### 4. 画面はユーザーランドが全画面取れる

- gfx の帯予約 (下 24px をカーネルが確保し、クライ
  アント領域から除外) は廃止し、画面全体 320x240 が
  窓の領分になる
- clock.elf は下帯の形をした窓を持つジョブとして
  描く。プログラムが全画面を取ったら帯ごと覆われ、
  時計は隠れる (我慢する側。realtime-design.md の
  優先と我慢の考え方)
- セーバーは時刻を描かず、暗転 + ブロック表示に
  寄せるのが方向 (最終形は実装時に詰める)

### 5. 常駐プログラム = スタートアップタスク

- Linux のサービスに当たるが、仕組みはシンプルに:
  初期化が済んだ後に決まったプログラムをジョブと
  して起こす「スタートアップタスク」だけを作る。
  監督 (落ちたら自動再起動) は付けない
- スタートアップに指定するプログラムは SD からも
  読み込める (initfs に入れる必要はない)
- 停止と再起動は欲しい: ジョブを終わらせる口として
  syscall 23 = job_kill を足し (番号方針: 20〜29 の
  プロセスブロック、doc/syscalls.md に先に書く)、
  Nish に kill コマンドを足す。再起動は kill して
  起こし直す形

### 6. initfs は最小限

- embed.S の分離先の名前は initfs (成果物
  initfs.img、セクション .initfs、カーネル側の
  登録部は initfs.c)。Linux の initramfs に対応する
  部品という位置づけ
- initfs に入るのは起動に要る最小限。ディスクに
  たどり着くためのドライバ級のものが入るのはよい
- 時計のようなサービスは初期化の後に SD から
  起こすので、initfs には入れない

### 7. Nish は getty 役とシェルに分ける

- 起動の層を Linux と同じ形に: カーネルは最初の
  ユーザープログラムを起こすところまで
- getty (名前は Unix の通称そのまま、getty.elf): コンソールの番人。
  スタートアップサービスを起こし、シェルを前面で
  起動し、シェルが exit したら起こし直す。今
  カーネルが担う「Nish の再起動」もここへ移す
- シェル: コマンドの解釈だけ。「Nish」の名前は
  シェル側に残す

## 実装の段立て (提案)

1. job_kill (syscall 23 + Nish kill) — 単独で
   検証でき、常駐の前提になる
2. gfx の帯予約廃止と全画面化
3. clock.elf + スタートアップ起動 + clock_body の
   痩せさせ
4. Nish と getty 役の分離
5. initfs 分離 (embed.S) — 別の段取りで
