# ima 設計メモ — 「今やってること」を LCD に大きく出す

2026-11-18 起案。置き時計になっている基板の LCD を、
作業状況の表示板としても使いたいという話から。

## 形

- 基板側は小さなユーザープログラム `ima.elf` 1つ。
  既存の gfx syscall (43〜47) だけで描く。新 syscall は
  足さない

      run ima <単語> [単語...]

  引数の単語を並べ、前面窓 (前面実行時の内容領域
  318x202) に入る最大の倍率 (scale 4→1) で折り返して
  中央に描く。単語がちょうど `|` のときは改行の合図
  (ブランチ名と一言を別行に分けるため)

- ブランチ名は基板には分からないので、ホスト側から
  送る。小さなスクリプト `show-status.py` (リポジトリ外、
  `~/workspace/kosaba-os/` に置く) が、git のカレント
  ブランチを拾い、Hatoba 経由で
  `run ima <ブランチ> | <一言>` を送る。送信は K210 の
  受信 FIFO に合わせて小分けにし、間隔を空ける

## 字形の制約 (実測)

- LCD のフォントは 5x7 ドット (字送り 6 ドット) で、
  字形があるのは **大文字 A〜Z、数字、! + - . : / >**
  だけ。小文字は空白になる
- そこで ima は描く前にテキストを大文字へ寄せる。
  ブランチ名 `fs-seek` は `FS-SEEK` と出る。小文字字形を
  フォント表へ足すのは別の段 (ボード層の話) として
  切り分ける
- gfx_text の 1 回は最大 48 文字。行の長さはこれでも
  制限する

## 描いた後の振る舞い (既存仕様の確認)

- ima が終わっても絵は前面窓に残る (描画 syscall の
  既存の意味づけ)。Nish の文字はシリアル側だけなので
  LCD は邪魔されない
- ただし無入力が続くとスクリーンセーバーが働く:
  段1 (60 秒) は時計帯だけなので絵は無事。段2 (300 秒、
  何も走っていないとき) に入ると絵は捨てられ大きな
  時計に替わる。表示を保ちたいときはホスト側から
  送り直す (再送自体が入力になるので段2 に入らない)

## 検証

- virt: test.sh シナリオ AG。ima が出す行 (ima: <行>、
  ima: done) と、dmesg の gfx text ログで判定する
- 実機: test-k210.py シナリオ K26 (シリアル側の行で
