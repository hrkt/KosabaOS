# synth — シンセ音源アプリの設計メモ (段1)

状態: 段1 実装 (2026-11-25、branch `synth-app`)。
コマンド名は **synth**。nami と同じく IwaC の C サブセットで
書き、iwac --kosaba --elf → nori でビルドする
(`arch/riscv64/synth/build-synth.sh`)。OS 側 build.sh は
成果物があるときだけ -DSYNTH_EMBED で取り込み、拡張子なしの
"synth" で登録する (nami と同じ流儀)。

## 使い方

- `run synth` / `run synth fm` — FM デモ曲 (32ステップ×0.25秒=8秒)
- `run synth psg` — PSG で同じデモ曲 (ノイズのハット付き)
- `run synth play fm` / `run synth play psg` — 対話モード
  - 鍵盤: 下段 `z s x d c v g b h n j m ,` と上段
    `q 2 w 3 e r 5 t 6 y 7 u i` が半音ずつ上がる 2 オクターブ
  - `o` / `p` で基準音 (既定 C4) をオクターブ上下、ESC / Ctrl-C で終了
- `run synth midi <path>` — MIDI バイト列ストリームを読んで鳴らす
  (下の SMF プレーヤーの節)
- 終了時に `synth: samples=<総数> fnv=<16進16桁>` と
  `synth: done` を印字する。virt では dmesg の
  `audio: close ... samples= / fnv=` 行と照合できる (wavgen の流儀)
- 戻り値: 0=正常、1=オーディオを開けない/書き込み失敗、2=引数不正

## 段1 の音源仕様

- 出力: 44100Hz・モノラル 16bit、audio syscall 40〜42 のみ
  (新 syscall なし)。書き込みは 1024 サンプル塊、部分受け付けは再送
- 共通ボイス: 4 ボイス、ラウンドロビン割り当て。簡易 ADSR
  (attack 約2.5ms、decay で sustain 61% へ、gate が切れたら
  release 約25ms)。状態は 1 ボイス 16 ワードで g_vs (下記) に持つ
- FM: 2 オペレータ。搬送波の位相を変調波 (周波数比 3.5) で変調。
  正弦波は 256 点 Q15 テーブル + 線形補間、位相は 1 周=65536 の
  固定小数点。変調の深さは専用エンベロープで減衰する
  (ベル / エレピ寄り)。音程表は MIDI 36〜96 の位相増分を
  ホストで計算し、関数内で代入で埋める (初期化子は使わない)
- PSG: 矩形波 (デューティ 50%)。ノイズは 16bit LFSR を
  1 チャンネルとして同じボイス枠で扱う
- ミキサー: 全ボイスを整数で加算し ±30000 でクリップ

## 割り切り (段1)

- 端末にはキーアップが無いので、対話モードでもキーを押すと
  gate (約0.36秒) 分だけ鳴って自動で release に入る。
  本当のゲート (押している間鳴る) は MIDI 入力待ち
- 現行の audio リングは 8192 フレーム (約186ms) なので、
  対話モードの発音遅延はその分ある。低遅延化は OS 側
  realtime-prep (doc/realtime-audio-design.md) の段2 の仕事で、
  synth 側は現行の口のまま追随する
- 実効レートは K210 で 44010Hz のため音程は約 -0.2% 低い
- ファイルスコープには char 配列だけ置き、表とボイス状態は
  その中へ rd32 / wr32 (バイト合成) で読み書きする
  (nori の配置ずれ対策、doc/nami-design.md)
- main に大きなローカル配列 (正弦波表など) を置くと IwaC の
  フレーム生成が壊れることを実測した (フレーム 1504 バイトで
  プロローグの `addi sp,sp,-N` の符号が反転して +N になり、
  スタック上端の外へ書いて即フォールト。nami の main は
  フレーム 80 バイト)。ローカルはスカラだけに保つこと。
  IwaC 側で直すべき問題として切り分ける

## SMF プレーヤー (smfplay)

Standard MIDI File を再生する別プログラム `smfplay`
(`arch/riscv64/synth/smfplay.c`、synth と同じく IwaC 製、
build-synth.sh が一緒にビルドし、OS 側は素材があるときだけ
拡張子なしの "smfplay" で取り込む)。

- 役割分担: smfplay は**仮想 MIDI デバイス**。SMF を解析し、
  テンポマップに従って実時間に刻みながら (uptime=31 で読み、
  sleep_ms=34 で待つ)、生の MIDI バイト列を送り先へ出す。
  synth は届いたバイト列をそのまま解釈して鳴らす
  (実鍵盤と同じ経路)
- **デルタ先送りをしない理由**: ファイル内のデルタタイムは
  SMF 形式そのものなので解析には使うが、送り先へデルタを
  渡して受け手に数えさせる形は取らない。本物の MIDI の線に
  タイミング情報は無く、バイト列が演奏時刻に届くこと自体が
  実物だからで、先送りすると時計の仕事が synth 側へ移り、
  実経路のジッタも検証できなくなる
- 送り先は `send_event()` の関数境界の向こう。本命は OS 側
  realtime-prep 段4 の L2 入力キュー + 注入 syscall で、
  来たらそこへ差し替える。暫定経路は 2 つ:
  - `run smfplay <file.mid>` — イベントを時刻つきログに
    出す (検証用)
  - `run smfplay <file.mid> file <path>` — 生バイト列を
    その時刻にファイルへ書いていく。終わりに終了マーカー
    として private SysEx `F0 7D 00 F7` を書いて閉じる
    (実キューが来るまでの暫定約束)
- synth 側の受け手は `run synth midi <path>`: ファイルを
  バイト列ストリームとしてポーリング読み (未着分は
  sleep_ms で少し待って再試行) し、逐次解釈する。
  ノートオン/オフは本物のゲート (オフで release)、
  プログラムチェンジは暫定で 0=FM音色 / 1=PSG音色、
  CC 120/123 は全音止め。終了マーカーで余韻 11025
  サンプルを描いてから閉じる。同時実行 (smfplay を
  ジョブで流しながら synth が読む) も virt で確認済み
- 対応範囲: format 0 / 1 (全トラックを時刻順にマージ、
  テンポは同一 tick なら小さいトラック番号を優先)、
  division は PPQ のみ (SMPTE は断る)、ランニング
  ステータス、テンポ設定メタ FF 51、トラック終了 FF 2F。
  SysEx と他のメタは読み飛ばす。ベロシティの大きさは
  synth 側で使わない (0=オフの扱いだけ守る)
- 制限: ファイルは丸ごと読みで上限 32768 バイト、
  イベント最大 4096、テンポ最大 256、トラック最大 32
- virt 検証 (2026-11-25): テスト曲 (make_test_mid.py、
  format 0/1 両版、テンポ変更 2 回、約 10.3 秒) で
  log モードのイベント時刻が予定と最大 11ms 差で一致、
  ファイル経由のパイプラインと同時実行ライブ再生の
  両方で synth の samples/FNV が audio close 行と一致

## 段立て全体

- **段1 (今回): FM + PSG** — 上記。共通ボイス/ミキサー/ADSR の枠を作る
- **段2: Roland LA 音源風** — 短い PCM アタック (打鍵・撥弦の
  頭だけ) + 減算合成のサステイン部、という LA 合成の骨格。
  アタック素材の持ち方 (埋め込み表か /sd のファイルか) が論点
- **段3: PCM 風** — サンプルそのものをオシレータとして使う
  (ループ再生、ピッチシフトは再サンプリング)。素材は /sd 前提
- **段4: アナログシミュレーション** — 鋸波/パルス + ローパス
  フィルタ + レゾナンス、オシレータのドリフトとデチューンで
  「揺れ」を作る。フィルタは 1 サンプル毎の固定小数点演算が本命
- **その先: ミキサー / エフェクト / MIDI 入力** — リバーブ・
  ディレイと、OS 側 realtime-prep 段4 の MIDI 入力 (DIN/UART)
  に接続して鍵盤で弾く。複数プログラムのミキシングは当面せず、
  音源+ミキサー+エフェクトを synth 1 本に内蔵する形で足りる

## 実機での確認手順 (次の手順)

1. `synth/build-synth.sh` で synth.elf を作り、OS を BOARD=k210 でビルド
2. Hatoba の file_push + RECV.ELF で synth.elf を SD へ送るか、
   埋め込みビルドのカーネルを SRAM ブートする
3. Nish から `run synth fm` / `run synth psg` を実行し、
   耳で FM (ベル寄り) と PSG (矩形波+ノイズ) を確認する。
   under=0 や FNV 一致だけで「きれいに鳴った」とは言わず、
   判定は耳で行う (nami の教訓)
