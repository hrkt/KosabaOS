# RISC-V 命令メモ (riscv64)

`start.S` で使った命令だけを集めた早見表。「これ何だっけ」を
なくすためのもの。新しい命令を使ったらここに足していく。

書き方の約束:

- `rd` は結果を入れるレジスタ、`rs` は元のレジスタ、`t0` のような
  具体名で書いた場合は実際の使われ方
- 「疑似命令」と書いたものは、本物の命令ではなく、アセンブラが
  本物の命令 (の組) に置き換えてくれる便利な省略形

## 値を入れる・計算する

### li — Load Immediate (疑似命令)

レジスタに数をそのまま入れる。

```asm
li a7, 1          ; a7 = 1
li t0, 0x10000000 ; t0 = UART のアドレス
```

値の大きさによって、裏では `addi` だけ、あるいは `lui` + `addi`
などに展開される。「とにかくこの数を入れて」と頼む書き方。

### lui — Load Upper Immediate

即値の上位 20 ビットをレジスタに入れ、下位 12 ビットは 0 にする。
計算: `rd = 即値 << 12`。

```asm
lui t0, 0x10000   ; t0 = 0x10000000
```

逆アセンブル結果に現れる。大きなアドレスを作る土台になる命令。

### auipc — Add Upper Immediate to PC

「今いる場所 (PC)」を基準にアドレスを作る。計算:
`rd = PC + (即値 << 12)`。4KB ページ単位の大ざっぱな移動が役目で、
細かい位置合わせはペアの `addi` が行う。

```asm
auipc sp, %pcrel_hi(stack_top)  ; stack_top のあるページへ
```

`%pcrel_hi(目標)` は「PC から目標までの距離の上位部分」という
アセンブラへの指示。`la` 命令と違い GOT を経由しないので、
裸のカーネルでも動く。

### addi — Add Immediate

レジスタに小さい数を足す。計算: `rd = rs + 即値`。
即値は 12 ビット符号付き (-2048 〜 +2047)。

```asm
addi sp, sp, %pcrel_lo(.Lsp) ; ページ内の細かい位置合わせ
addi s1, s1, 1               ; ポインタを 1 文字分進める
```

`%pcrel_lo(ラベル)` は、直前の `auipc` とペアで使う下位部分の指示。

### andi — And Immediate

レジスタと即値の AND (ビットごとの AND) を取る。計算:
`rd = rs & 即値`。「特定のビットだけを取り出す」ための命令。

```asm
andi t1, t1, 0x20  ; LSR の bit5 だけを残し、他を 0 にする
```

## メモリとデバイスを読む・書く

メモリも MMIO のデバイスも、住所を指定して読み書きする点は同じ。

### lbu — Load Byte Unsigned

住所から 1 バイト読み、上位を 0 で埋めてレジスタに入れる。

```asm
lbu a0, 0(s1)   ; 文字列の今の位置から 1 文字読む
lbu t1, 5(t0)   ; UART の LSR (+5) を読む
```

`0(s1)` は「s1 の住所 + 0」の意味。括弧内が基準のレジスタ、
前の数がずれ (オフセット)。

### sb — Store Byte

レジスタの下位 1 バイトを住所へ書く。

```asm
sb a0, 0(t0)    ; UART の THR (+0) へ 1 文字置く = 送信される
sb t1, 3(t0)    ; UART の LCR (+3) に設定を書く
```

## 分岐と呼び出し

### beqz — Branch if Equal to Zero (疑似命令)

レジスタが 0 ならラベルへ飛ぶ。本体は `beq rs, zero, ラベル`。

```asm
beqz a0, 2f     ; 文字が 0 (文字列の終わり) なら前方ラベル 2 へ
beqz t1, 1b     ; bit5 が 0 (送信窓口がまだ) なら後方ラベル 1 へ
```

数字ラベルの後ろの `f` は前方 (forward)、`b` は後方 (backward)。

### j — Jump (疑似命令)

無条件にラベルへ飛ぶ。本体は `jal zero, ラベル`
(戻り先を捨てる jal)。

```asm
j 1b   ; ループの先頭へ戻る
```

### call — 関数呼び出し (疑似命令)

ラベルへ飛び、戻り先の住所を `ra` に記録する。裏では
`auipc` + `jalr` の 2 命令。相手は `ret` で戻る。

```asm
call uart_putc  ; a0 の 1 文字を出す部品を呼ぶ
```

### ret — Return (疑似命令)

`ra` に記録された戻り先へ飛ぶ。本体は `jalr zero, ra, 0`。

## その他

### wfi — Wait For Interrupt

割り込みが来るまで CPU を眠らせる。仕事が無いときの「駐車」に使う。

```asm
2:  wfi   ; 眠る
    j 2b  ; 目覚めてもまた眠る
```

### ecall — Environment Call (今は使っていない)

下の階層 (S モードからなら OpenSBI) を呼ぶ命令。以前の版は
`a7 = 1` で SBI の「1 文字出して」を呼んでいた。UART ドライバを
自前で持ったので不要になり、現在のカーネルには含まれていない。
将来、ユーザープログラムから OS を呼ぶ「システムコール」でも
同じ命令が (逆向きに) 登場する。
